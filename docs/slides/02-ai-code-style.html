Code Style

In general, we will use the tidyverse style guide for guidance on how to format our code.

Good code formatting makes it easier for others to read your code! Since you will be collaborating with others throughout the course, it is important to write code that is easy to understand!

Universal Principles

  • Spaces before and after = (e.g., mean = mean(x))
  • Spaces after commas (e.g., aes(x = hwy, y = cty))
  • No line of code should be over 80 characters long.
    • If your line is longer than 80 characters, you should use new lines (returns) to break up your code.
    • The contents should be indented by two spaces.

Why use the pipe?

The pipe is a powerful way to make your code more readable by passing the output of one funtion as the input of the next function.

No more nested functions!

## Good
map(diamonds, summ_stats) |> 
  bind_rows(.id = "id")

## Bad
bind_rows(map(diamonds, summ_stats),
          .id = "id")

Which pipe to use?

As of R 4.3.0, the base pipe (|>) provides all the features from magrittr (%>%) that we recommend using.

Let’s demo how to get the base pipe as the default!

Saving Intermediate Objects

Objects should only be saved if they are needed to be refereced later!

  • Bad
  • Good
summ_stats <- function(x){
  if(is.numeric(x)){
    mean = mean(x)
    median = median(x)
    sd = sd(x)
    iqr = IQR(x)
    summary <- tibble(Mean = mean, 
                      Median = median,
                      SD = sd,
                      IQR = iqr)
    return(summary)
  } else if (is.factor(x) || is.character(x)) {
    num_levels = n_distinct(x)
    summary <- tibble(`Number of Levels` = num_levels)
    return(summary)
  } else {
    warning("Unsupported input type")
    return(NULL)
  }
}
summ_df <- function(dataframe){
  if(is.data.frame(dataframe)){
    
    dataframe |>
      map(summ_stats) |>
      bind_rows(.id = "variable") |>
      pivot_longer(
        cols = -variable,
        names_to = "statistic",
        values_to = "value") |>
      pivot_wider(
        names_from = variable,
        values_from = value)
    
  } else {
    warning("Input is not a dataframe")
  }
}
